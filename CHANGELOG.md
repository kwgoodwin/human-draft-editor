# Changelog

## 1.0.1 — 2026-11-12

- Added explicit protection for quantifiers, scope, degree, modal verbs, and tense or timing.
- Defined the boundary of a light edit and made audit output location-specific and prioritized.
- Preserved author conventions and cross-section consistency; narrowed follow-up rounds to newly requested changes.
- Added a distinct item-by-item comparison pass and optional change-list or markup delivery.
- Clarified that strict draft-only output cannot carry an appended factual-warning note.
- Added six synthetic regression scenarios for these behaviors.

## 1.0.0 — 2026-11-10

- First public portable edition: audit, light-edit and rewrite modes.
- Optional voice and high-stakes meaning-preservation guidance.
- Synthetic examples and 20 regression scenarios with a limited literal checker.
- Bounded Astra critique, Sol review and targeted retest evidence.
- Explicit handling of incompatible constraints and quoted instructions.

The production Clearon integration is not part of this release.
